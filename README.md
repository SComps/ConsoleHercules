## REXX Automation & Event Scripting
HyperionTUI features a universal event log detection engine and REXX automation framework for Hercules and guest operating systems.
You MUST have rexx installed for it to work.  See the ScriptData subdirectory for the Master REXX code.

For instructions on writing REXX event handlers, see the [REXX Scripting Manual](file:///e:/HyperionTUI/ScriptData/REXX_SCRIPTING_MANUAL.md).
